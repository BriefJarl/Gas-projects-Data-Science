# Gas Price Analysis

A data science project focused on analyzing and forecasting gas prices using historical price data.

## Contents

* `gas_cost.csv` — Gas cost dataset
* `Gas_prices_folder/gas_prices.csv` — Historical gas price data
* `gas_forecast.py` — Forecasting and analysis code
* `seasonality_by_month.png` — Monthly seasonality analysis
* `timeseries_forecast.png` — Time-series forecasting visualization

## Tools

* Python
* Pandas
* NumPy
* Matplotlib
* Time-Series Analysis

> Private repository — project source code and data are not intended for redistribution.
